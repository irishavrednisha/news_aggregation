## Запуск из Windows PowerShell

Рабочее окружение активировать не требуется:

```powershell
cd D:\Projects\news_aggregation
git fetch origin
git switch --track origin/test/stage4-independent-holdout-2026-11-20

.\.venv\Scripts\python.exe scripts\stage4_independent_holdout.py --exclude collector_test_results\stage4_abstractive_v5_100.json --mode both --target 100 --minimum 40 --max-age-days 30 --out-dir collector_test_results\stage4_independent_holdout
```

Скрипт читает проверенные кластеры из PostgreSQL и собирает новые
публикации активных источников через collect_news(session=None).
Он **ничего не записывает в БД**, не вызывает MAX и не отключает TLS.
Для нового материала нужны валидный URL, заголовок, полный HTML-текст
от 350 символов и дата публикации за последние 30 дней. Материалы
старого отчёта используются **только для исключения** по URL, точному
тексту и близкому заголовку. Источники распределяются с ограничением
до 15 на один сайт; найденные в БД многодокументные кластеры
сохраняются, а новые сайты не склеиваются в один кластер наугад.

**Ограничение:** по близости заголовков нельзя гарантировать, что
другие издания не пересказали старое событие. При дальнейшей
разметке этот факт требуется проверять вручную.

Если доступно менее 40 независимых полных статей, команда завершается
с кодом 2 **до запуска Gemma**, сохраняя манифест и причины отказов.
Целевая выборка — 100 новых событий; 40 — лишь минимальный
исследовательский пробник, недостаточный для утверждения о готовности
к публикации. Если многодокументных кластеров нет, итоговый
вывод относится **только** к однодокументной суммаризации.

Если прервалась генерация, повторить **те же аргументы** и добавить
`--resume`. Манифест останется прежним; уже вычисленные строки
используются только с совпадающими хешами и версией.
Для пересбора нового набора использовать **другой --out-dir**.
Опцию `--allow-undated` не использовать для финальной проверки,
иначе нельзя подтвердить свежесть публикаций.

Режим без записи в БД и без нового обращения к сайтам:
`--mode diagnostics --diagnostics-json collector_test_results/all_sources_diagnostics.json`
— работает, только если ранее использовался
`scripts/diagnose_all_sources.py --include-text`.
Опция `--collect-only` подготавливает выборку без Gemma.

## Критерии оценки человеком

Каждую сводку оценить по пяти **отдельным** критериям:

1. faithful_facts — подтверждены все факты: организации, субъектные
   связи, деньги, числа, единицы, даты, прогнозы и причинно-следственные связи;
2. natural_russian — связная естественная русская новость без
   падежных, стилистических и синтаксических ошибок;
3. main_event_covered — сохранена суть события, а не второстепенные детали;
4. meaningful_news_event — это реальная своевременная новость, а не
   реклама, справка или устаревший анонс;
5. source_quality — первоисточника достаточно; он не содержит чужих
   вставок и не обрезан.

Заполнить значения **pass / fail / na**, а в error_details —
причину и цитату из оригинала. Пустую сводку не оценивать
как ложный факт: ставить na. Самостоятельная модель не
имеет права заполнять эти поля своими вердиктами.
